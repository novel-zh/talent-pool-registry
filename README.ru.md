# Реестр кадрового резерва

**Вставьте ссылку на Google Таблицу — приложение само создаст анкеты и фильтры по её столбцам.**

[English](README.md) · [Установка и настройка](docs/setup.md)

![Подключение таблицы по ссылке](docs/images/connection-screen.png)

Автономная версия на Google Apps Script больше не привязана к двум конкретным таблицам,
названиям столбцов, уровням или трекам. Ссылку вводят в самом приложении: редактировать код
и задавать свойства скрипта для каждой новой таблицы не нужно.

## Как работает

1. Один раз разверните приложение по [инструкции](docs/setup.md).
2. Откройте его, войдите в Google и вставьте ссылку на свою Google Таблицу.
3. Приложение найдёт строку заголовков, доступные поля и типы данных.
4. Выберите лист, ищите записи, добавляйте фильтры и раскрывайте полные анкеты.

Подключение сохраняется отдельно для каждого пользователя. Нужен доступ к исходному файлу.
При подключении приложение ничего не записывает в таблицу и не добавляет служебные ID.

## Автоматические фильтры

| Столбец | Фильтр |
| --- | --- |
| Небольшой набор текстовых значений — например, регионы или статусы | Выпадающий список |
| Имена и произвольный текст | Поиск по тексту |
| Числа | От / до |
| Даты Google Таблиц | Диапазон дат |
| Флажки и логические значения | Да / нет |
| Любое поле | Заполнено / не заполнено |

Названия полей берутся из заголовков. Повторяющиеся и пустые заголовки получают понятные
различимые подписи. Смешанные типы отображаются как текст. Телефоны и идентификаторы
сохраняют видимое форматирование, включая ведущие нули.

Если шапка сложная, откройте «Источник и лист» и задайте строку заголовков вручную.
Автоматический поиск смотрит первые 20 строк; вручную доступны строки 1–30.

![Анкеты и фильтры на вымышленных данных](docs/images/participant-editor.png)

## Дополнительные возможности

- Поиск по всем полям, сортировка, страницы списка и выбор видимых столбцов.
- Полная анкета со всеми найденными полями и мобильный вид карточками.
- Редактирование и добавление записей через автоматически построенную форму.
- Проверка доступа Google Таблиц; существующие ячейки с формулами не редактируются.
- Проверка версии строки перед сохранением и попытка восстановления при ошибке записи.
- Демонстрационный режим с вымышленными данными, который включается только отдельной кнопкой.

## Что нужно установить

Отдельный сервер не нужен. Достаточно один раз создать Apps Script-проект из пяти файлов:
`Code.gs`, `Index.html`, `Model.html`, `Client.html`, `appsscript.json`.
Разверните веб-приложение **от имени пользователя, открывающего приложение**.
После этого новые таблицы подключаются обычной ссылкой через интерфейс.

Это приложение Apps Script: для реальных, в том числе закрытых, таблиц нужна опубликованная
версия и авторизация Google. Простое открытие HTML или GitHub Pages позволяет показать пример,
но не даёт доступа к личным таблицам.

## Ограничения

Показывается один лист за раз; автоматического объединения разных листов по ФИО нет.
Нужна одна строка заголовков и одна запись на строку. Пустому листу сначала добавьте заголовки.
Лимиты чтения: до 5 000 исходных строк, 100 столбцов, 100 000 ячеек и около 2 млн символов.
При частичной загрузке интерфейс предупреждает, что поиск и фильтры работают только по загруженной части.

Приложение не добавляет постоянные ID: сохранение проверяет номер и версию строки.
После внешних изменений или сортировки может потребоваться обновление. Откат записи выполняется
по возможности и не является транзакцией базы данных. Формулы и оформление в новые строки
не копируются. Защищённые диапазоны могут включить режим просмотра для всего загруженного блока.

Проверки: `node tests/backend.cjs` и `node tests/model.cjs`.
Дополнительные браузерные тесты и структура проекта описаны в [English README](README.md).
Реальные анкеты, рабочие ссылки и ключи в репозиторий не входят. Лицензия пока не выбрана.
