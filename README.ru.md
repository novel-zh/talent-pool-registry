# Реестр кадрового резерва

**Веб-приложение Google Apps Script для работы с анкетами и планами развития в Google Таблицах.**

[English](README.md) · [Настройка](docs/setup.md)

![Форма добавления участника — вымышленные данные](docs/images/participant-editor.png)

Основной реестр и таблица анализа объединяются в одном интерфейсе: поиск, фильтры,
страницы списка, раскрывающиеся анкеты, редактирование и добавление участников.
Данные остаются в исходных Google Таблицах.

## Возможности

- Связь двух источников по стабильному `Сотрудник_ID`.
- Единая форма редактирования с учётом доступа пользователя к каждой таблице.
- Проверка версии записи перед сохранением и попытка отката при сбое записи.
- Проверка дат и защита текстовых полей от случайного выполнения формул.
- Адаптивный интерфейс, общая прокрутка и кнопка «Наверх».

## Настройка

1. Подготовьте две Google Таблицы. Для демонстрации импортируйте вымышленные CSV из `examples/`.
2. Создайте проект Apps Script и добавьте `Code.gs`, `Index.html`, `appsscript.json`.
3. В свойствах скрипта задайте параметры из `config.example.json` — файл служит образцом.
4. С правами редактора обеих таблиц выполните `initializeEmployeeIds`, затем `checkConnection`.
5. Разверните веб-приложение **от имени пользователя, открывающего приложение**.
6. Ограничьте аудиторию и предоставьте нужным пользователям доступ к таблицам.

Подробнее — в [инструкции](docs/setup.md). Инициализация записывает ID в таблицы:
для первой проверки используйте копии. Неоднозначные совпадения ФИО требуют ручного разбора.
Откат между двумя файлами выполняется по возможности и не является транзакцией базы данных.

Заголовки столбцов на русском и немецком описаны в `SCHEMA_`; их можно адаптировать.
Приложение предназначено для ведения записей и не принимает кадровых решений.

В репозитории нет рабочих анкет, контактов, ссылок на таблицы или развёртывание.
Не открывайте персональные данные анонимным посетителям. Лицензия пока не выбрана.
